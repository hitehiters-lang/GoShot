## GoShot
GoShot is golang based program, that checks clipboard every second (you can change it in config.json) and saves every pictures in specified directory (also in config.json).

## Installation

1. Download latest version from [Releases](https://github.com/hitehiters-lang/GoShot/releases)
2. Edit `config.json` in the same directory
3. Run `GoShot.exe`
4. Now your screenshots saving to directory from config.json

P.S. GoShot running without cmd and you can kill it only from task manager, because of the windows console input blocking
